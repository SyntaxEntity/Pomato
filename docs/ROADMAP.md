## 3. 需要先征求用户同意的事

以下操作**不得擅自执行**，必须先获得用户明确同意：

| 操作 | 原因 |
|---|---|
| `git init` | 用户约束；**当前无任何版本控制**（无 `.git`） |
| 创建 GitHub 远程仓库并 push | 属上级管理 agent 的事务范围，需用户决策仓库名与可见性 |
| bump 版本号 + `cargo generate-rpm` + 交付安装 | **当前处于版本冻结期**，用户明确说「先不要打包」 |
| 扩大功能范围（上表第 2 节任一项） | 用户明确划定过边界 |
